¿Para qué sirve realmente Active Directory?Active Directory (desarrollado por Microsoft) es un servicio de directorio que centraliza la administración de usuarios, equipos, permisos y políticas de seguridad.En una red sin AD (un grupo de trabajo o Workgroup):Cada ordenador gestiona sus propios usuarios y contraseñas de forma local.Si cambias la contraseña de un usuario, tienes que cambiarla máquina por máquina.No hay una forma centralizada de aplicar políticas de seguridad (como bloquear el uso de USBs o forzar el cambio de clave).En una red con AD (un dominio):Creas el usuario una sola vez en el servidor central (Controlador de Dominio).El usuario puede iniciar sesión en cualquier equipo de la empresa con las mismas credenciales.El administrador puede aplicar reglas globales (Políticas de Grupo o GPO) a cientos de equipos al mismo tiempo.¿Cuándo NO es necesario?Hogares y microempresas (1 a 10 equipos): La complejidad y el coste de mantener un servidor con Windows Server no justifican el beneficio.Entornos 100% Cloud: Empresas que trabajan exclusivamente con navegadores y SaaS suelen optar por soluciones basadas en la nube como Microsoft Entra ID (antes Azure AD), Google Workspace o JumpCloud.Redes heterogéneas sin predominio de Windows: Si la mayoría de equipos usan Linux o macOS, existen alternativas más nativas (como LDAP, FreeIPA o OpenDirectory).Comparativa: Con AD vs. Sin ADCaracterísticaSin Active Directory (Workgroup)Con Active Directory (Dominio)Gestión de usuariosDescentralizada (equipo por equipo)Centralizada en un único servidorEscalabilidadMuy difícil a partir de 10-15 equiposMuy alta (miles de usuarios y equipos)Políticas de seguridadConfiguración manual en cada PCDespliegue automático (GPOs)Coste e infraestructuraBajo / NuloRequiere licencias y servidores dedicadosInicio de sesión único (SSO)NoSí (Kerberos / NTLM)
